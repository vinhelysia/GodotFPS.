## 4. Save compatibility boundary

Native Cogito objects/NPCs save parent path and local pose. CSM replaces current
Persist nodes with snapshot instances. Changing parents can make restoration
skip objects; retaining names/parents alone does NOT migrate old coordinates.
Legacy direct Town saves can put player/loot/NPC/corpses into new walls/terrain.

The supported production route remains fresh Hub deployment and preserved Hub
stash/carried state. Use isolated fresh raid fixtures for layout verification.
Do not delete user saves, silently apply old poses as a migration, or promise
legacy direct Town snapshot geometry compatibility. If migration becomes a user
requirement, propose its policy before adding it; keep it outside this art pass.
